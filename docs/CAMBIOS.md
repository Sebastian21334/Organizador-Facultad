## Decisiones de alcance

- El pedido menciona `[ARCHIVO DE ESTRUCTURA]`, pero no incluye un nombre real y no se encontró un documento de arquitectura ni `AGENTS.md` en el repositorio. Se toma la distribución existente como contrato: `front/src/app/{core,features,shared}`, módulos de Nest en `back/src` y App Router en `Modulo chat`. No se mueven ni renombran carpetas. Las oportunidades de reorganización se documentan sin aplicarlas.
- La revisión abarca las tres aplicaciones. La investigación y auditoría preceden a cualquier modificación del código de producto.
- Las pruebas visuales usan datos locales de prueba, sin enviar correo, notificaciones ni mensajes a personas ni modificar cuentas reales. Se distinguirá la simulación de API de las pruebas reales del backend.
- Los resultados de cada fase se guardan en `docs`. Capturas y mediciones se conservarán junto a los informes para que puedan revisarse.
